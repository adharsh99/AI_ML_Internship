# AI Fundamentals

## 1. What is Artificial Intelligence?

Artificial Intelligence (AI) is a branch of computer science that focuses on creating systems capable of performing tasks that normally require human intelligence.

Examples include:

- Understanding language
- Recognizing images
- Making predictions
- Solving problems
- Recommending products
- Understanding speech
- Generating content

---

## 3. What is Machine Learning?

Machine Learning (ML) is a subset of Artificial Intelligence that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every situation.

For example, a machine learning model can learn from historical house prices and predict the price of a new house.

---

## 4. Types of Machine Learning

### 4.1 Supervised Learning

In supervised learning, the model learns from labeled data.

Example:

Input:

- House size
- Number of bedrooms
- Location

Output:

- House price

Common algorithms:

- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine

---

### 4.2 Unsupervised Learning

In unsupervised learning, the data does not have predefined labels.

The algorithm attempts to find patterns or groups within the data.

Example:

Customer segmentation.

Common algorithms:

- K-Means Clustering
- Hierarchical Clustering
- PCA

---

### 4.3 Reinforcement Learning

In reinforcement learning, an agent learns by interacting with an environment.

The agent receives:

- Rewards for good actions
- Penalties for poor actions

Examples:

- Game-playing AI
- Robotics
- Autonomous systems

---

## 5. What is Deep Learning?

Deep Learning is a subset of Machine Learning that uses artificial neural networks with multiple layers.

Deep learning is particularly useful for:

- Image recognition
- Speech recognition
- Natural Language Processing
- Generative AI
- Computer vision

Examples include:

- Face recognition
- Voice assistants
- Image generation
- Large Language Models

---

## 6. AI vs ML vs Deep Learning

| Technology | Meaning |
|---|---|
| AI | Broad field of intelligent computer systems |
| ML | AI systems that learn patterns from data |
| Deep Learning | ML using multi-layer neural networks |

Relationship:

```text
Artificial Intelligence
        |
        └── Machine Learning
                |
                └── Deep Learning
```

## 7. Advantages of AI

- Automation
- Faster decision making

---

## 8. Limitations of AI

- Requires quality data
- Can be expensive to develop
- May produce incorrect predictions
- Requires monitoring
- Can introduce bias if training data is biased
