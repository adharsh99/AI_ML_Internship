# Expense Tracker

## Project Overview

Expense Tracker is a Python-based console application developed as part of the AI & ML Internship (Module 2 – Python Mini Project). It helps users manage their daily expenses by allowing them to add, view, search, and generate expense reports. The application stores data in CSV format and provides a simple, user-friendly interface.

---

## Features

- Add a new expense
- View all expenses
- Search expenses by category
- Calculate total expenses
- Generate monthly expense summary
- Save expense records to a CSV file
- Generate expense reports

---

## Technologies Used

- Python 3
- CSV File Handling
- Functions
- Conditional Statements
- Loops
- Exception Handling
