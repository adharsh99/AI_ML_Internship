# Project Requirements – Expense Tracker

## 1. Project Title

**Expense Tracker**

## 2. Project Description

Expense Tracker is a Python-based application used to record and manage daily expenses.

The application allows users to add, view, search, update, and delete expenses. It also calculates expense summaries and generates monthly reports.

## 3. Objectives

* Create an expense management application using Python.
* Store expenses in a CSV file.
* Add, view, search, update, and delete expenses.
* Calculate total and average expenses.
* Generate category-wise and monthly summaries.
* Validate user input.
* Perform basic unit testing.

## 4. Features

* Add Expense
* View Expenses
* Search Expense
* Update Expense
* Delete Expense
* Expense Summary
* Monthly Report
* Generate Reports
* Input Validation
* CSV File Storage

## 5. Technologies Used

* **Python**
* **CSV**
* **Unittest**
* **VS Code**
* **Git & GitHub**

## 6. Expense Details

Each expense contains:

| Field          | Description           |
| -------------- | --------------------- |
| ID             | Unique expense ID     |
| Date           | Date of expense       |
| Category       | Expense category      |
| Description    | Expense details       |
| Amount         | Money spent           |
| Payment Method | Cash, UPI, Card, etc. |

## 7. Categories

* Food
* Travel
* Shopping
* Bills
* Education
* Entertainment
* Health
* Other

## 8. Requirements

The application requires:

* Python 3.x
* VS Code
* Basic knowledge of Python

## 9. Expected Result

The application should allow users to easily manage their expenses and view useful expense summaries.

## 10. Future Enhancements

## 11. Conclusion

The Expense Tracker provides a simple way to manage daily expenses while demonstrating practical Python programming concepts.
