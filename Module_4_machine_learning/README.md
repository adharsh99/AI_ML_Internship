# Module 4 - Machine Learning Fundamentals

## 🏠 Project: House Price Prediction Using Machine Learning

---

## 📌 Project Overview

This project is part of Module 4 of the Codomax AI/ML Internship.

The main objective of this project is to understand the fundamentals of Machine Learning and build a model that can predict house prices based on different house features.

In this project, a **Linear Regression** Machine Learning model is used to predict the price of a house based on:

- Area
- Number of Bedrooms
- Number of Bathrooms
- Age of the House

The project demonstrates the complete basic Machine Learning workflow from data preparation to prediction and evaluation.

---

## 🎯 Objectives

The main objectives of this project are:

- Understand the basics of Machine Learning
- Understand Supervised Learning
- Understand Regression
- Work with a house price dataset
- Explore and analyze the dataset
- Check missing and duplicate values
- Visualize the data
- Select input features and target variable
- Split the dataset into training and testing data
- Build a Linear Regression model
- Train the Machine Learning model
- Make house price predictions
- Evaluate the model performance
- Predict the price of a new house

---

## 🧠 What is Machine Learning?

Machine Learning is a branch of Artificial Intelligence that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every situation.

Machine Learning can be broadly divided into:

1. Supervised Learning
2. Unsupervised Learning
3. Reinforcement Learning

This project uses **Supervised Learning** because the dataset contains known house prices that are used to train the model.

---

## 📚 Type of Machine Learning

### Supervised Learning

Supervised Learning is a type of Machine Learning where the model learns from data that contains both input values and known output values.

In this project:

### Input

- Area
- Bedrooms
- Bathrooms
- Age

### Output

- House Price

The model learns the relationship between the input features and the house price.

---

## 📈 Regression

Regression is a Machine Learning technique used when the output is a continuous numerical value.

Examples of regression problems include:

- House price prediction
- Salary prediction
- Sales prediction
- Temperature prediction
- Stock price estimation

Since house price is a numerical value, this project is a **Regression problem**.

---

## 🤖 Machine Learning Algorithm

### Linear Regression

Linear Regression is a supervised Machine Learning algorithm used to predict a continuous numerical value.

In this project, Linear Regression learns the relationship between house features and house prices.

The model tries to find the best relationship between the input variables and the target variable.
