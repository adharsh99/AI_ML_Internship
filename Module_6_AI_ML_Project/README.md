# 🤖 AI Job Matching System

## 📌 Project Overview

The AI Job Matching System is a machine learning project designed to recommend suitable job roles based on a candidate's skills, education, and experience.

This project demonstrates the practical use of Python, Machine Learning, and Streamlit to build an AI-powered job recommendation application.

## 🎯 Objectives

- Analyze candidate information
- Identify relevant skills
- Match candidate skills with suitable job roles
- Provide job recommendations
- Build an interactive web application using Streamlit

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning
- Streamlit
- Pickle

## ⚙️ How the Project Works

1. The user enters their name.
2. The user provides their skills.
3. The user enters their education.
4. The user selects their experience level.
5. The system analyzes the provided skills.
6. Suitable job roles are recommended.
7. The results are displayed in the Streamlit application.

## 💻 Run the Project Locally

### 1. Create Virtual Environment

python -m venv venv

### 2. Activate Virtual Environment

For Windows PowerShell:

venv\Scripts\Activate.ps1

### 3. Install Required Packages

pip install pandas numpy scikit-learn streamlit

### 4. Run the Application

python -m streamlit run main.py

### 5. Open in Browser

The application will provide a local URL such as:
http://localhost:8502
