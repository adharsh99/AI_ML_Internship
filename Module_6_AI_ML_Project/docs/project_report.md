# AI Career Assistant - Project Report

## 1. Project Title

AI Career Assistant – Resume Analyzer, Job Matcher & Interview Coach

## 2. Objective

The objective of this project is to develop an AI-powered career
assistant that helps users analyze resumes, match job descriptions,
identify skill gaps and practice interviews.

## 3. Features

- Resume PDF analysis
- AI-powered resume analysis
- Job matching
- Skill gap identification
- Job role recommendation
- AI interview question generation
- Interview answer evaluation

## 4. Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- PyPDF
- Groq API
- NLP
- Machine Learning

## 5. Project Workflow

Resume PDF
↓
Text Extraction
↓
AI Resume Analysis
↓
Skill Extraction
↓
Job Description Matching
↓
ML Job Recommendation
↓
AI Interview Coaching

## 6. Expected Outcome

The system provides users with useful career insights,
job matching information and interview preparation assistance.

## 7. Future Enhancements

- LinkedIn job integration
- Multiple resume comparison
- Voice-based interview
- Advanced ATS scoring
- Personalized learning recommendations
